# 📺 Iptv 🌐

A repository containing an M3U playlist of streaming channels. 🎬📻

## 📁 Contents

- 📋 `playlist.m3u` is the playlist.
- 🏷️ Channel entries include names and, where supplied, group and logo metadata.
- 🔗 Stream URLs point to external services.

<a id="-open-the-playlist"></a>

## 🔹 ▶️ Open the playlist

Open `playlist.m3u` in a player that supports M3U playlists. 🖥️🎧

## 🛠️ Editing

- 📝 Keep the `#EXTM3U` header and each `#EXTINF` entry in valid M3U form.
- 🔗 Keep the stream URL on the line after its channel information.
- 🧭 Check edited entries in your chosen player.

<a id="ℹ-project-scope"></a>

## 🔹 ℹ️ Project scope

This repository contains playlist data, not a standalone player application. 📂 Stream availability depends on the external source. 🌍
